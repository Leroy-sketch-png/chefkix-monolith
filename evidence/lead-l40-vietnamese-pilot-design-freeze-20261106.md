## Adopted question and scope

For a deliberately varied, rights-cleared set of Vietnamese recipe-conditioned replacement requests, what do two independent native-speaking cooks record about the frozen primary GISMo top-five candidate slate, and—within a separately counted declared-constraint cohort—what mechanical violation, unknown, withholding and abstention states result when the existing C3 filter is applied to those same candidates?

This is a bounded descriptive instrument/coverage pilot. It is not representative of Vietnamese cuisine, a causal cuisine comparison, a model-arm tournament, product-utility evidence, a clinical/allergen-risk study, or a safety certification. The two cohorts are reported separately; there is no pooled 100-case headline.

## Frozen design decisions

1. **Cases and targets.** Target `N=100`: 60 culinary-validity cases and 40 declared-allergen-constraint cases, with separate denominators and results. One case is one source-recipe cluster × one exact target slot × one stated task. Select at most one case per recipe cluster across both cohorts. No title-only, translated-title, fuzzy, model-generated, or guessed cross-source join. Case-specific identity failures discovered after the frame is frozen remain in that cohort's denominator as explicit failures/unknowns; do not guess or halt unrelated cases.
2. **Source eligibility and rights.** Use first-party/authored or external Vietnamese recipe sources only when the actual per-case terms support the planned private storage, adaptation, frozen-arm processing, blinded reviewer access, and aggregate reporting. Record the applicable source/version and restricted rights reference in the local manifest. Unchecked terms, incompatible terms, missing source provenance, missing permission for a planned operation, or required identity/context facts without evidence exclude the record before sampling with a reason. The HUMAN's existing internal permission/consent attestation is accepted as such; it is not expanded into blanket source rights or public-release permission. Do not read or publish confidential internal permission records.
3. **Frame and coverage.** Preserve original Vietnamese text in UTF-8 with diacritics. Require a usable title, ingredient list, target, and enough source context for the task; insufficient context is an explicit exclusion. Region must be evidenced or native-reviewed as North/Central/South. Assign one primary dish family using the existing contract's list: noodle soup, rice, grilled/braised, roll, dipping sauce, sweet soup, sandwich, other, or unknown. The seven named families have coverage targets only where eligible records exist; `other`/`unknown` never fill a named-family target.
4. **Allocation and shortfall.** Culinary cohort region targets are 20/20/20 (North/Central/South); constraint cohort targets are 14/13/13. Target at least five cases per named family in the 60-case cohort and three in the 40-case cohort where eligible. M-B uses the existing deterministic least-filled region×family-cell round-robin rule; ties use the pre-draw seed-derived case rank and stable private case ID. Freeze the rights-cleared, deduplicated eligible-frame manifest before selection. Derive the sampling seed as the big-endian integer represented by the first 8 bytes of `SHA256(b"iron-chef-l40-sampling-v1\0" + bytes.fromhex(frame_manifest_sha256))`. No quota transfers or post-output replacement. If a cohort cannot meet its total or fixed regional targets, stop that cohort before outputs and retain an aggregate shortfall/exclusion receipt; the other cohort may proceed only if it independently meets its own gates. If a named-family target is infeasible despite the eligible-frame audit, preserve its shortfall and do not claim that family was covered; do not invent examples.
5. **Language and contributors.** Vietnamese is the primary human-review language; the frozen GISMo arm receives only its existing typed inputs, not an English gloss or newly translated prompt. Require a checked English gloss for every selected case as a secondary audit field, produced by a qualified bilingual human; preserve the original and keep the gloss out of model inputs and blinded primary review. Preserve candidate names in their original form and use only a versioned native-reviewed identity/gloss where available; an unintelligible or ambiguous candidate is `U`, not silently translated into an identity. If a checked case gloss is unavailable before selection, record a pre-sampling exclusion and frame shortfall rather than switching to a half-translation design. The source-authorship floor is two contributors including a native cook. Two qualified Vietnamese-speaking cooks independently review every candidate; neither may have authored or selected the case they review. Keep authoring, reviewing, and adjudication roles separate and recorded privately.
6. **Frozen arm and slate.** Use only the existing Protocol-v1 primary GISMo released-checkpoint arm, with its exact model artifact, input schema, task parameters, and vocabulary/catalog identity pinned in the pre-output manifest. Do not add lookup, Senath/Mistral, GPT/Gemini, or another arm; this is not a model comparison and creates no new paid/API arm. If the shared frozen artifact or input contract fails preflight, stop the affected cohort before any output; a case-specific unmatched identity is a retained per-case failure and does not stop unrelated cases. Include the GISMo top five where an exact frozen input is available. Include a recorded source gold only when the source itself supplies one with an exact source/hash; label it blind but exclude it from the model top-five denominator. Keep raw candidate strings and source/arm origins; use the pinned exact identity for primary deduplication, with unmatched/ambiguous strings retained and never fuzzy-promoted.
7. **Constraint cohort and C3 filter.** The 40-case frame requires an explicitly declared constraint and a source-backed relationship between that declared allergen group and an exact source-recipe ingredient form, established before candidate output. The record must cite a source that supports that exact relation; the WHO/IUIS positive seed is not exhaustive, and ontology/taxonomy membership alone is not empirical product evidence. The prompt may contain the declared constraint, but not hidden source evidence, reviewer labels, or adjudication. Generate one raw GISMo slate and apply the already frozen C3 filter to those same candidates; do not call the model again for the filtered arm. Record declared-group and trace states separately as `yes/no/unknown/not_applicable` only where the frozen source contract supports them. Unknown or ambiguous evidence is withheld, never treated as `no`; an empty filtered list is abstention, not safety.
8. **Review and case outcomes.** Independently label every slate candidate `A/C/N/U` under the existing C1 rubric, in randomized order, with reviewers blind to model position/origin, raw-versus-filtered membership, and any gold indicator. Preserve raw labels and separate versioned adjudication. For a per-arm five-candidate slate: `V=1` if at least one final adjudicated `A`; `V=0` only if there is no `A` and all five are `C` or `N`; otherwise `V=unknown`. Keep unknowns in the fixed denominator; report lower/upper success bounds, not complete-case rates. `A+C` is a separately named sensitivity. Do not transfer L36's 0.15 decision boundary or weighted unseen-stratum estimator to L40.
9. **Outcomes, missingness, and interpretation.** Freeze each cohort's case IDs before generation. Every case has either its valid output or an explicit method/parse/identity failure. Every candidate has a label or explicit `U`, missing, withdrawn, or unresolved state. Consent-required deletion takes precedence; retain only a permitted non-identifying flow count. Report per cohort and region/family: eligible→selected→frozen→attempted→labeled flow, actual denominators, method/parse failures, candidate-level A/C/N/U, case-level lower/upper strict-A@5 bounds, A+C sensitivity, source-evidence coverage, raw/filtered violation/unknown/withholding counts, removed-candidate labels, remaining pool and abstentions. Candidates are nested, not independent cases. For binary case-level proportions, report two-sided Wilson intervals as descriptive summaries of this purposive frame only; report paired raw/filtered transition counts and fixed-denominator bounds, not a significance test or population effect. Use the frozen Protocol-v1 rater convention: proceed at Tier-1 kappa ≥0.5; say “reliable agreement” only if the strict-kappa case-cluster-bootstrap 95% lower bound is ≥0.6; otherwise call results exploratory. No interval from fewer than 20 valid bootstrap draws. No clinical, population, causal, generalization, or product-usefulness claim follows.

## Rationale, alternatives, and falsifiers

The design keeps the full proposed 60/40 ambition and regional/family targets while using one already frozen primary arm and same-output C3 filtering. This isolates the pilot's Vietnamese-context and filter-coverage questions without paid calls, new model families, or a disguised tournament. The strongest alternative is multiple arms (e.g., GISMo plus lookup/Senath) for comparative validity; that changes the estimand and candidate burden, so it requires a separate prospective design, not silent expansion. A seeded-half gloss would reduce translation workload but create a second language-coverage stratum; full checked glosses are selected for a single auditable secondary record, never as model/reviewer input.

The design is falsified as executable if the eligible source frame cannot support a cohort's fixed target/region quotas, source rights do not cover a planned operation, frozen GISMo identity/input contracts fail, or constraint cases lack exact-form source evidence. The pre-output shortfall rule then applies; no lowered N, arm substitution, fuzzy identity, quota transfer, or post-result redesign is permitted. Review if the actual source frame demonstrates these conditions, if the pinned GISMo artifact is incompatible with Vietnamese inputs, or if a methods reviewer identifies a concrete conflict with C1/C3 frozen semantics. A revision must be versioned before outputs and must preserve the original design/results.

**Perspective check:** cooks' context is assessed in Vietnamese; English is secondary and cannot override it. Accessibility is served by preserving native text and disclosing gloss coverage. Privacy is served by restricted source IDs/rights records and no source rows in shared Git. Safety language is limited to mechanical evidence coverage/withholding. The pilot's scholarly value is a bounded audit, not a product-quality claim. Operationally, quotas are explicit, failures remain visible, and the default is no output on identity/rights mismatch. Engineering reuses the existing C1/C3 types; it adds no framework or production behavior.
